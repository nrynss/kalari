Kalari plugs into the coding agent you already use. It turns API upgrades into checks that must pass, runs the agent code in a throwaway microVM, and records what broke so the next upgrade lands clean.

An API consumer has to move to a new version. A coding agent can write the migration, but its word is not proof. The obvious migration often returns HTTP 200 and still loses data. In the reference run, a v1 importer exited 0 with 100 items while 2,331 of 2,431 records were gone.

## See it live

The agent does the coding. Kalari decides what has to be checked, what is at stake, what was learned, and whether the result is proved. Read the <DocLink to="architecture/">Architecture</DocLink> page for the full picture in five minutes.
